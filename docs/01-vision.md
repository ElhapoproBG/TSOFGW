# Visión y principios

1. **Dinamismo nativo:** el motor no impone una estructura; el desarrollador compone y reemplaza nodos.
2. **Bajo nivel resuelto:** TSOFGW abstrae hardware (Vulkan/Metal/D3D12, OpenXR); el desarrollador trabaja en alto nivel y puede ajustar parámetros sin tocar el motor entero.
3. **Costo proporcional al uso:** lo que nadie necesita no consume.
4. **Entrada fácil al mercado MMO:** el sistema primario (cuentas, red, persistencia, despliegue) viene como nodos.
5. **Confianza verificable:** open source no es "confía en mí"; es firmas, builds reproducibles y permisos declarados.
6. **Interoperabilidad con límites:** se comparte identidad y perfil; economías (monedas, inventarios) solo bajo reglas explícitas.
